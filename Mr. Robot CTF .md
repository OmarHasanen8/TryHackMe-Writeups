## 📖 Writeup Format

Each writeup follows a structured penetration testing report format:

1. **Executive Summary** — High-level overview and key findings
2. **Scope & Methodology** — Target scope and testing approach
3. **Technical Findings** — Step-by-step exploitation with commands
4. **Attack Chain Summary** — Visual flow of the full compromise
5. **Vulnerability Summary** — CVE/CVSS ratings per finding
6. **Remediation Recommendations** — Actionable fixes
7. **Flags** — Retrieved keys/flags
